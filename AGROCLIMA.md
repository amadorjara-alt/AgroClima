# Sistema Web de Monitoreo Agroclimático · AgroClima

Esta es la aplicación activa del repositorio y se publica desde la raíz en GitHub Pages. El propósito del proyecto es apoyar la planificación agrícola con terrenos georreferenciados, datos meteorológicos, alertas por umbral e historial por usuario.

- Sitio: https://amadorjara-alt.github.io/AgroClima/
- Dashboard: `dashboard.html`
- Guía de ejecución y rúbrica: [README.md](README.md)
- Modelo de datos: [docs/MODELO_DE_DATOS.md](docs/MODELO_DE_DATOS.md)
- Arquitectura y demostración: [docs/ARQUITECTURA_Y_DEMO.md](docs/ARQUITECTURA_Y_DEMO.md)
- SQL de Supabase: `supabase/migrations/20261110090000_agroclima.sql`

La app usa Supabase Auth y PostgreSQL con RLS; Open-Meteo; Nominatim; Leaflet; Chart.js. Los archivos anteriores del proyecto pueden conservarse en el repositorio como referencia, pero ya no forman parte de la navegación ni del propósito de la aplicación desplegada.
